== bugs found & fixed en route ==
1. banded constructor wrote rel_extent via `op_params + 16` = int32 arithmetic = byte 64 =
   ONE PAST the op_params array (into tensor->flags + padding). Harmless by luck (kernels
   read rel->ne[0]; nothing reads the slot). Fixed: op_params[4] (byte 16) for rel_extent,
   op_params[6] (byte 24) for visibility_window.
2. LLAMA_BATCH_DEBUG=1 + no-vocab fixture: ubatch_print calls vocab->token_to_piece →
   out_of_range throw on the empty piece cache → server dies at the load-time
   common_context_can_seq_rm probe. Fixed: skip piece lookup for LLAMA_VOCAB_TYPE_NONE.
